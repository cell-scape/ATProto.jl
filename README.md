# ATProto.jl

[![Build Status](https://github.com/cell-scape/ATProto.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/cell-scape/ATProto.jl/actions/workflows/CI.yml?query=branch%3Amain)

## Description

Julia ATProto SDK

Based on reference implementations in Typescript and Go, and on community implmentations of the same.

## Documentation

Reference code implementations are in the docs/reference directory.
- The Typescript implementation is the most complete and authoritative according to the developers. (docs/reference/atproto)
- The Go implementation and tools are maintained by the developers.
- The other implementations, Python, Elixir, Rust, Zig, etc. are community implementations are are in various states of completeness.

Up to date Atproto docs can be found at https://atproto.com/docs

- Auth: atproto.com/guides/auth
  - SDK Auth: atproto.com/guides/sdk-auth
  - About Oauth: atproto.com/guides/about-oath
  - Permission Requests: atproto.com/guides/permission-requests
  - Permission Sets: atproto.com/guides/permission-sets
  - Oauth Patterns: atproto.com/guides/oauth-patterns
  - Scope Builder: atproto.com/guides/scope-builder
